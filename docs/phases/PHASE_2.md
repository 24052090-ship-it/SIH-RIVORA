# AquaGuard Phase 2 Scope

## Objective
Move from a frontend-only prototype to a persistent, authenticated, GIS-ready full-stack foundation.

## Completed
1. Express REST API
2. PostgreSQL + PostGIS schema
3. JWT auth
4. Role-based access
5. Database seed data
6. Real user registration/login
7. Citizen/authority dashboard summaries
8. GIS GeoJSON flood zones
9. Sensors, drains and roads in PostGIS
10. Rainfall readings
11. Reports and alerts
12. Maintenance records
13. Health endpoint
14. Frontend service integration

## Deferred intentionally
- FastAPI ML
- YOLO/OpenCV
- Socket.IO
- ESP32/MQTT
- Satellite processing
- Production cloud deployment

These belong to later phases.
