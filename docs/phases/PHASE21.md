# AquaGuard Phase 21 — Real-Data ML Training Pipeline

Phase 21 connects approved Phase-20 datasets to a reproducible ML training/evaluation workflow.

Includes:
- approved-dataset manifest
- feature engineering contract
- time-aware train/validation/test split guidance
- XGBoost training entry point
- evaluation metrics
- model artifact manifest
- explicit synthetic-vs-real data labeling
- no automatic promotion to production

This phase does not claim real-world accuracy until approved local data is supplied.
