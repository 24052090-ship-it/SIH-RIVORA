# Phase 22 Model Evaluation

Evaluate a candidate model against a held-out test set.

Recommended evidence:
- precision, recall, F1, ROC-AUC and PR-AUC
- confusion matrix
- calibration/reliability
- performance by rainfall intensity
- performance by geographic zone
- false-negative review
- temporal holdout performance
- comparison with the current production model

Suggested release gates should be agreed using local operational requirements. The project must not invent a safety-critical threshold without validation.
