# AquaGuard Vision Dataset

Add locally collected/licensed images and YOLO-format labels.

Classes:
0 blocked_drain
1 overflowing_drain
2 flooded_road
3 waterlogging
4 open_manhole
5 garbage_blockage

Directory structure:
- images/train
- images/val
- labels/train
- labels/val

Do not train on unlabeled or copyrighted images without permission. Keep train/validation scenes separated to avoid leakage.
